Entrega antes de la clase de la Semana 3, vía **Google Classroom** —
todavía no usamos Git ni GitHub para entregar tareas (eso empieza en la

## Qué entregar

Completa los `# TODO` de `tarea-02.ipynb` con tu solución, usando los
nombres exactos de clase, propiedades y métodos que pide cada enunciado. No
necesitas escribir ningún archivo `.py` ni tocar la carpeta `tests/`.

Ten en cuenta que el ejercicio 2 te pide **volver a escribir la clase
completa** agregándole los operadores. Los tests califican la clase tal
como queda definida en esa última celda, así que asegúrate de copiar ahí tu
solución del ejercicio 1.

## Antes de entregar

Corre tu notebook completo desde un kernel limpio (`Kernel → Restart & Run
All`) y confirma que llega hasta el final sin errores. Un notebook que no
ejecuta completo no se puede calificar.
