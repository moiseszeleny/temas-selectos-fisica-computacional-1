# Roster

Lista de forks del curso, para que el asistente pueda ubicar y revisar las
entregas de cada estudiante. Se llena con un PR por estudiante — ver
["Tu primer PR: agrégate al roster"](git-guia.md#tu-primer-pr-agrégate-al-roster)
en `docs/git-guia.md`.

Solo se pide usuario de GitHub, no nombre completo, para minimizar datos
personales en un repositorio público.
