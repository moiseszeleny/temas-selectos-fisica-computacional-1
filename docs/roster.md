# Roster

Plantilla del primer PR de cada estudiante (práctica de Git de la semana 3)
— ver ["Tu primer PR: agrégate al roster"](git-guia.md#tu-primer-pr-agrégate-al-roster)
en `docs/git-guia.md`. Ese PR se abre **dentro del fork** de cada quien, así
que la tabla de abajo se llena en cada fork, no aquí.

Para ubicar las entregas, el asistente no usa esta tabla sino la lista de
forks que da GitHub (ver "Qué ve el profesor / asistente" en
[`autograding.md`](autograding.md)).

Solo se pide usuario de GitHub, no nombre completo, para minimizar datos
personales en un repositorio público.
